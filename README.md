# webЯcade Applications: Atari Jaguar, Atari Jaguar CD Emulators

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

This repository contains [webЯcade](https://www.webrcade.com) applications for the following systems:

* [Atari Jaguar](#atari-jaguar)
* [Atari Jaguar CD](#atari-jaguar-cd)

The underlying emulator is a modified version of the Libretro fork of [Virtual Jaguar](https://github.com/libretro/virtualjaguar-libretro).

## Atari Jaguar

The Atari Jaguar application for [webЯcade](https://www.webrcade.com) is an emulator for the [Atari Jaguar game console](https://en.wikipedia.org/wiki/Atari_Jaguar).

### Documentation

The [Atari Jaguar Application Documentation](https://docs.webrcade.com/apps/emulators/jaguar/) includes [keyboard](https://docs.webrcade.com/apps/emulators/jaguar/#keyboard) and [gamepad](https://docs.webrcade.com/apps/emulators/jaguar/#gamepad) control mappings, information about the on-screen [Keypad](https://docs.webrcade.com/apps/emulators/jaguar/#keypad), and details regarding the use of the emulator within a [webЯcade feed](https://docs.webrcade.com/apps/emulators/jaguar/#feed).

## Atari Jaguar CD

The Atari Jaguar CD application for [webЯcade](https://www.webrcade.com) is an emulator for the [Atari Jaguar CD](https://en.wikipedia.org/wiki/Atari_Jaguar_CD), a CD-ROM add-on for the Atari Jaguar released in 1995.

 </a>

### Documentation

The [Atari Jaguar CD Application Documentation](https://docs.webrcade.com/apps/emulators/jaguarcd/) includes [control mappings](https://docs.webrcade.com/apps/emulators/jaguarcd/#controls) (shared with the Atari Jaguar application), information related to [save data](https://docs.webrcade.com/apps/emulators/jaguarcd/#saves) support, and details regarding the use of the emulator within a [webЯcade feed](https://docs.webrcade.com/apps/emulators/jaguarcd/#feed).
